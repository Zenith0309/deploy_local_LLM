# Harness 基础与实践

## 1. Harness 是什么

在 Agent 系统中，**Harness（运行框架/控制线）** 是包裹模型和工具的工程层。它负责让 Agent 在真实环境中按规则运行，而不是只返回一段文本。

可以这样区分：

- **模型**：提出下一步建议。
- **Agent**：围绕目标进行决策。
- **工具**：执行具体动作。
- **Harness**：决定哪些动作可以执行、如何记录、何时停止、失败后如何恢复。

Harness 不是某一个固定产品名称，而是一组运行时能力。一个脚本、SDK 封装、任务执行器或编排服务都可以实现 Harness。

## 2. Harness 的核心职责

| 能力 | 要解决的问题 |
| --- | --- |
| 生命周期管理 | 创建任务、恢复任务、取消任务和清理资源 |
| 上下文组装 | 控制消息、工具说明、历史和检索内容如何进入模型 |
| 工具路由 | 根据模型动作找到工具，并完成参数校验 |
| 权限与策略 | 限制文件、网络、命令、数据和高风险操作 |
| 状态持久化 | 保存步骤、工具结果、检查点和最终状态 |
| 超时与预算 | 防止死循环、资源耗尽和费用失控 |
| 观测与审计 | 记录请求、工具调用、延迟、错误和结果 |
| 验证与恢复 | 检查结果，在失败时重试、回滚或暂停 |

## 3. 一个可控的 Harness 流程

```text
接收任务
  ↓
创建任务状态与预算
  ↓
组装上下文并调用模型
  ↓
解析模型输出
  ├─ 最终答案 → 验证 → 成功或要求修正
  └─ 工具调用 → 权限校验 → 执行 → 记录 → 回到模型
  ↓
超时、取消或失败时保存检查点并结束
```

关键点是：模型输出不应直接触发副作用。所有工具调用都要经过 Harness 的解析、校验和授权。

## 4. 最小状态模型

建议至少保存以下字段：

```text
task_id
status: pending | running | waiting | succeeded | failed | cancelled
step_count
started_at / finished_at
input_summary
messages_or_context_ref
tool_calls
last_error
budget_usage
checkpoint
```

大型上下文不一定要全部放进状态记录。可以保存内容引用、哈希和元数据，并把实际内容放在受控存储中。

## 5. 重试与恢复

重试前先区分错误类型：

- **参数错误**：返回明确错误，让模型修正参数，不要盲目重复。
- **临时网络错误**：可以指数退避重试，并设置最大次数。
- **权限错误**：停止并请求授权，不应自动重试。
- **业务冲突**：重新读取状态或进入人工处理。
- **模型格式错误**：尝试结构化修正或重新请求，但要限制次数。

有副作用的工具必须考虑幂等性。为写操作携带任务 ID 或幂等键，可以避免网络超时后重复创建、重复发送或重复扣款。

## 6. Harness 与 Agent 的边界

把业务规则放在 Harness，而不是只写在系统提示词里：

- “只能读取某个目录”应由文件系统沙箱或路径校验保证。
- “发送前必须确认”应由状态机阻塞等待确认。
- “最多调用五次工具”应由计数器强制执行。
- “不能访问公网”应由网络策略或运行环境限制。
- “输出必须是 JSON”应由解析器和 Schema 验证。

提示词可以帮助模型理解规则，但不能作为唯一的安全控制。

## 7. 评测 Harness

不要只看最终回答是否自然。建议记录：

- 任务完成率
- 工具参数正确率
- 平均和 P95 延迟
- 平均工具调用次数
- 超时、重试和人工接管比例
- 越权调用拦截次数
- 上下文长度和资源占用

使用固定任务集做回归测试，至少覆盖正常路径、工具失败、模型输出格式错误、超时、取消和重复执行。

## 8. 本地部署的实现建议

如果使用 Ollama 作为模型服务，可以把 Harness 放在 Python、Node.js 或其他应用进程中：

```text
本地应用 / Harness
       ├── 调用 Ollama API
       ├── 校验工具参数
       ├── 读写任务状态
       └── 输出日志与指标
              ↓
        Ollama 推理服务
              ↓
          本地模型
```

先实现单任务、单 Agent、少量只读工具，再逐步增加写操作、长期记忆和并发。这样更容易定位问题，也能避免把模型能力、工具错误和编排错误混在一起。
