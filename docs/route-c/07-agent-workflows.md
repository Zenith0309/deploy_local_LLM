# 7. Agent 工作流设计

## 1. 固定工作流和 Agent 的区别

固定工作流适合步骤、分支和审批都明确的业务；Agent 适合下一步取决于中间结果的任务。生产系统通常采用混合模式：

```text
固定节点：鉴权、预算、审批、写入、通知
动态节点：检索策略、工具选择、问题拆解
```

## 2. 常见模式

- **顺序链**：摘要 → 分类 → 生成。
- **条件分支**：根据结构化结果选择路径。
- **循环**：执行、验证、修正，设置最大次数。
- **规划-执行**：先形成任务清单，再逐项完成。
- **人机协作**：高风险节点暂停等待批准。

## 3. 设计步骤

1. 画出确定性流程。
2. 标出必须由代码保证的规则。
3. 只把不确定部分交给 Agent。
4. 为每个节点定义输入、输出和错误。
5. 为循环设置停止条件。
6. 为写操作增加审批和幂等。

## 4. 验收

使用正常、分支、超时、工具失败和人工拒绝五类测试，确认每条路径都有终态，并且失败不会静默变成成功。
